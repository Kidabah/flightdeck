# Flightdeck v0.4.0-beta.1

Status: Bambu-focused public beta candidate.

## Beta Focus

This release is intended for testers running Bambu printers, especially X1C/H2D with AMS or AMS HT.

## Highlights

- Bambu live printer cockpit with camera, controls, print state, and filament route.
- Fleet Wall and Flight Tower for multi-printer monitoring and queue attention.
- Spool inventory with Swatch, Detail, Table, Cabinet, Stock In, and Filament catalogue views.
- QR/mobile spool assignment to printer, AMS, and AMS HT slots.
- Automatic filament deduction when print metadata and slot assignment are available.
- Print History with spool usage correction/reconcile paths.
- Print Vault, queue, reprint, and Bambu file workflows.
- Windows tray install path and Windows slicer helper tooling.
- Browser Orca/Bambu Studio health checks and clearer offline warnings.
- Camera worker watchdog and safe restart scripts.
- Setup health and diagnostics bundle for beta feedback.

## Recommended First Test

1. Install on Raspberry Pi 5.
2. Add one Bambu printer.
3. Add one shelf/location and one spool.
4. Assign that spool to the physical AMS/AMS HT slot.
5. Queue or reprint a small test file.
6. Confirm print history and spool deduction.
7. Download diagnostics if anything looks wrong.

## Known Limitations

See [Beta limitations](../BETA_LIMITATIONS.md).

Most important:

- Treat this as Bambu-first.
- Do not expose Flightdeck publicly.
- Some direct-slicer jobs may need History correction if Flightdeck did not receive filament metadata.
- H2C support should wait for real hardware testing.

## Upgrade Notes

Pull latest code and restart safely:

```bash
cd ~/flightdeck
git pull
./scripts/install.sh
sudo ./scripts/safe-restart-flightdeck.sh
```

Back up first if the install is important:

```bash
./scripts/backup-flightdeck-data.sh
```
